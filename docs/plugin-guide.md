# DevOps Terminal Dashboard - Plugin Development Guide

This guide explains how to develop plugins for the DevOps Terminal Dashboard.

## Plugin Architecture

Plugins for the DevOps Terminal Dashboard are Go plugins that implement the `Plugin` interface. They are loaded at runtime and can provide custom metrics, notifications, and visualizations.

### Plugin Directory Structure

Plugins are stored in the `plugins` directory (or a custom directory specified in the configuration):

```
plugins/
  aws/
    aws.so        # Compiled plugin
    README.md     # Documentation
  kubernetes/
    kubernetes.so
    README.md
```

### Plugin Interface

All plugins must implement the following interface:

```go
type Plugin interface {
	// Initialize initializes the plugin with the given configuration
	Initialize(config map[string]interface{}) error

	// Name returns the name of the plugin
	Name() string

	// Version returns the version of the plugin
	Version() string

	// Description returns a brief description of the plugin
	Description() string

	// Collect collects data from the plugin source
	Collect() (interface{}, error)

	// GetMetrics returns metrics collected by the plugin
	GetMetrics() []models.Metric

	// GetNotifications returns notifications generated by the plugin
	GetNotifications() []models.Notification

	// GetConfigSchema returns the configuration schema for the plugin
	GetConfigSchema() map[string]string

	// Shutdown performs cleanup when the plugin is unloaded
	Shutdown() error
}
```

## Creating a Plugin

### Step 1: Set Up Your Plugin Project

Create a directory for your plugin:

```bash
mkdir -p myplugin
cd myplugin
```

Initialize a Go module:

```bash
go mod init github.com/yourusername/myplugin
```

### Step 2: Implement the Plugin Interface

Create a file named `myplugin.go` with the following content:

```go
package main

import (
	"fmt"
	"time"

	"github.com/Teomazivila/maz-term/pkg/models"
	"github.com/Teomazivila/maz-term/pkg/plugins"
)

// MyPlugin is an example plugin
type MyPlugin struct {
	name          string
	version       string
	description   string
	configured    bool
	interval      time.Duration
	metrics       []models.Metric
	notifications []models.Notification
	lastCollect   time.Time
}

// NewPlugin is the exported plugin constructor
func NewPlugin() plugins.Plugin {
	return &MyPlugin{
		name:          "myplugin",
		version:       "1.0.0",
		description:   "My custom plugin for DevOps Terminal Dashboard",
		interval:      30 * time.Second,
		metrics:       []models.Metric{},
		notifications: []models.Notification{},
		lastCollect:   time.Now(),
	}
}

// Initialize initializes the plugin with the given configuration
func (p *MyPlugin) Initialize(config map[string]interface{}) error {
	// Get interval from config, with fallback to default
	if intervalStr, ok := config["interval"].(string); ok {
		if interval, err := time.ParseDuration(intervalStr); err == nil {
			p.interval = interval
		}
	}

	p.configured = true
	return nil
}

// Name returns the name of the plugin
func (p *MyPlugin) Name() string {
	return p.name
}

// Version returns the version of the plugin
func (p *MyPlugin) Version() string {
	return p.version
}

// Description returns a brief description of the plugin
func (p *MyPlugin) Description() string {
	return p.description
}

// Collect collects data from the plugin source
func (p *MyPlugin) Collect() (interface{}, error) {
	// Skip collection if we're within the interval
	if time.Since(p.lastCollect) < p.interval {
		return p.metrics, nil
	}

	p.lastCollect = time.Now()

	// Example: Generate a dummy metric
	p.metrics = []models.Metric{
		{
			Name:      "myplugin.value",
			Value:     42.0,
			Unit:      "units",
			Timestamp: time.Now(),
			Source:    "myplugin",
			Tags: map[string]string{
				"type": "example",
			},
		},
	}

	// Example: Generate a notification
	notification := models.Notification{
		ID:        fmt.Sprintf("myplugin_%d", time.Now().UnixNano()),
		Title:     "MyPlugin Notification",
		Message:   "This is a notification from MyPlugin.",
		Timestamp: time.Now(),
		Severity:  models.NotificationInfo,
		Source:    models.SourceSystem,
		Read:      false,
		Dismissed: false,
	}

	p.notifications = []models.Notification{notification}

	return map[string]interface{}{
		"metrics":       p.metrics,
		"notifications": p.notifications,
	}, nil
}

// GetMetrics returns metrics collected by the plugin
func (p *MyPlugin) GetMetrics() []models.Metric {
	return p.metrics
}

// GetNotifications returns notifications generated by the plugin
func (p *MyPlugin) GetNotifications() []models.Notification {
	return p.notifications
}

// GetConfigSchema returns the configuration schema for the plugin
func (p *MyPlugin) GetConfigSchema() map[string]string {
	return map[string]string{
		"interval": "Duration between data collections (e.g., 30s, 1m)",
	}
}

// Shutdown performs cleanup when the plugin is unloaded
func (p *MyPlugin) Shutdown() error {
	p.configured = false
	return nil
}
```

### Step 3: Create a Makefile

Create a `Makefile` to build your plugin:

```makefile
.PHONY: build
build:
	go build -buildmode=plugin -o myplugin.so myplugin.go

.PHONY: install
install: build
	mkdir -p ../plugins/myplugin
	cp myplugin.so ../plugins/myplugin/
```

### Step 4: Build and Install Your Plugin

Build your plugin:

```bash
make build
```

This will create a `myplugin.so` file. 

Install your plugin to the dashboard's plugins directory:

```bash
make install
```

## Plugin Configuration

Plugins can be configured in the dashboard's `config.yaml` file:

```yaml
plugins:
  directory: "plugins"
  enabled:
    - "myplugin"
  settings:
    myplugin:
      interval: "10s"
```

## Plugin API Reference

### Metrics

Plugins can provide metrics using the `models.Metric` structure:

```go
type Metric struct {
	Name      string            `json:"name"`
	Value     float64           `json:"value"`
	Unit      string            `json:"unit"`
	Timestamp time.Time         `json:"timestamp"`
	Source    string            `json:"source"`
	Tags      map[string]string `json:"tags,omitempty"`
}
```

### Notifications

Plugins can generate notifications using the `models.Notification` structure:

```go
type Notification struct {
	ID          string               `json:"id"`
	Title       string               `json:"title"`
	Message     string               `json:"message"`
	Timestamp   time.Time            `json:"timestamp"`
	Severity    NotificationSeverity `json:"severity"`
	Source      NotificationSource   `json:"source"`
	Read        bool                 `json:"read"`
	Dismissed   bool                 `json:"dismissed"`
	ActionURL   string               `json:"action_url,omitempty"`
	ActionLabel string               `json:"action_label,omitempty"`
	Tags        []string             `json:"tags,omitempty"`
}
```

## Best Practices

1. **Error Handling**: Properly handle errors and avoid panics that could crash the dashboard.
2. **Resource Usage**: Minimize resource usage, especially in the `Collect()` method which is called frequently.
3. **Configuration**: Make your plugin configurable with sensible defaults.
4. **Documentation**: Include a README.md with your plugin that explains its functionality and configuration options.
5. **Hot Reload**: Your plugin should be designed to handle being unloaded and reloaded without causing issues.

## Testing Your Plugin

1. Build your plugin using `make build`
2. Install it to the dashboard's plugins directory
3. Add your plugin to the `enabled` list in the dashboard's configuration
4. Start the dashboard
5. Check the "Plugins" tab to see if your plugin is loaded correctly
6. Verify that your plugin's metrics and notifications are being displayed

## Troubleshooting

1. **Plugin Not Loading**: Check that the plugin file is in the correct location and has the correct name.
2. **Incompatible Interface**: Ensure your plugin implements all methods of the Plugin interface.
3. **Build Errors**: Make sure you're building with the correct Go version and build flags.
4. **Runtime Errors**: Check the dashboard logs for error messages related to your plugin.
